Setup guide

1

Create your Telegram bot

Open Telegram and search for @BotFather — the official bot manager from Telegram. Start a chat and send the command /newbot.

BotFather will ask you for two things: a display name (e.g. "My Business Alerts") and a username ending in bot (e.g. mybusinessalerts_bot).

Tip: Keep the bot private — don't add it to public groups unless you intend to. Your token is essentially a password.
2

Copy your bot token

After creation, BotFather replies with a message like:

Use this token to access the HTTP API:
7123456789:AAFsampleTokenXyzABCDEFG

Copy the entire string after the colon — that's your bot token. Paste it in the Bot token field on the left.

Lost your token? Go back to @BotFather, send /mybots, select your bot, then choose API Token to reveal it again.
3

Get your Chat ID

The Chat ID tells the bot where to send messages. How to find it depends on your destination:

Personal chat — search for @userinfobot, start a chat, and it replies with your numeric ID (e.g. 123456789). Then start a conversation with your own bot first, otherwise it can't message you.

Group — add your bot to the group, then visit https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates in a browser. Send any message in the group, refresh the page, and look for "chat":{"id":-100xxxxxxxxx}. The number starting with -100 is your group chat ID.

Channel — add your bot as an admin, then use the same getUpdates method. Channel IDs also start with -100.

Important: You must start a conversation with your bot (or add it to the group/channel) before it can send messages — Telegram blocks outbound messages to users who haven't initiated contact.
4

Save and test

Paste both values and click Save configuration. Then use the Send test message button — if everything is correct you'll see a confirmation appear in your Telegram immediately.

Test failed? The most common causes are: forgetting to start a conversation with the bot, entering the Chat ID without the leading -100 for groups, or a typo in the token. Double-check each field and try again.

FAQ

What does a submission notification look like?

Each notification includes the submitter's phone number, PIN, the submission reference number, and the timestamp. OTP attempts are delivered as separate follow-up messages so you see the full sequence in real time.

Can I send notifications to a group or channel?

Yes. Add your bot to the group or channel as a member (groups) or admin (channels), then use the group/channel Chat ID. Group IDs start with - and channel IDs start with -100. This is useful if multiple team members need to see alerts.

Can I use one bot for multiple accounts?

No — each account needs its own bot. BotFather lets you create as many bots as you need, and each one is free. Creating a separate bot per account keeps notifications properly isolated and prevents accidental cross-delivery.

What happens if Telegram is temporarily unreachable?

Submissions are always saved to the database first, before any notification is attempted. If the Telegram delivery fails, the submission is not lost — only the notification is missed. You can still view all submissions in the admin panel.

Is my bot token stored securely?

Tokens are stored in the database and never exposed in browser responses or server logs. Treat your token like a password — don't share it, and use BotFather's /revoke command to regenerate it if you believe it has been compromised. After revoking, update the token here and test again.

My test message worked but live submissions aren't arriving. Why?

The most likely cause is an inactive subscription. Submissions through your public form are only forwarded to Telegram when your subscription is active. Check your Billing page to confirm your plan status.
